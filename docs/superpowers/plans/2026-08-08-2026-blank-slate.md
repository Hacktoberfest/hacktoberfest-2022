# 2026 Blank Slate Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Strip all 2025 Hacktoberfest content (pages, components, hooks, lib data, theme, assets) out of this Next.js static-export site, leaving only `/` and a 404 page as bare placeholders, while keeping the site buildable and deployable exactly as it is today.

**Architecture:** This is a deletion/reduction task, not a feature build. Tasks are ordered so the build stays green after every single commit. This ordering is load-bearing, not arbitrary: `src/pages/_app.js` currently wraps every page in a styled-components `ThemeProvider` (via the `Theme` component), and `404.js`, `index.js`, `about.js`, and `events.js` all use styled-components that read from that theme context. If `_app.js` loses its `ThemeProvider` before every page that depends on it has been rewritten or deleted, `next build`'s static export throws (`Cannot read properties of undefined (reading 'eastBay')`) because the styled-components in the still-theme-dependent pages get no theme. So: rewrite `404.js` and `index.js` to bare components first (Tasks 1-2), delete `about.js`/`events.js` next since they're removed rather than rewritten (Task 3), and only once no page depends on the theme anymore does `_app.js` get stripped of its `ThemeProvider` (Task 4). After that, nothing references `components/`/`lib/`/`hooks/`/`themes/`/`assets/` and they're deleted in bulk (Tasks 5-6). Verification at every step is `npm run build` (the real build pipeline: custom pre-build script → `next build` static export) since there is no unit test suite — `npm test` is a prettier format check, not a test runner.

**Tech Stack:** Next.js 15 (static export, `output: 'export'`), React 19, styled-components (compiler-configured but will become unused after this plan — left in `package.json` per constraints).

## Global Constraints

- Do not change any dependency version, in `package.json` or `package-lock.json`, for any reason. Do not remove now-unused dependencies (`styled-components`, `html-react-parser`, `markdown-it`, `country-list`) either — leaving them is intentional per spec.
- Do not modify `next.config.js`, `package.json` scripts, `.do/deploy.template.yaml`, any file under `.github/workflows/`, `Makefile`, `.nvmrc`, `.husky/*`, `.editorconfig`, `.prettierrc`, `.lintstagedrc`, or `jsconfig.json`.
- Do not modify `src/build/index.mjs`, `src/build/robots.mjs`, `src/build/post/index.mjs`, or `src/build/post/cache.mjs` — only the `urls` data array inside `src/build/sitemap.mjs` changes (Task 3).
- Do not modify `src/pages/_document.js`.
- Do not modify `public/.well-known/security.txt`, `public/health`, or `public/.gitignore`.
- Do not modify `.do/deploy.template.yaml` even though its ingress redirects to `/about`/`/events` anchors become dangling after this plan — that's flagged in the spec as explicitly out of scope, not fixed.
- Final site must have exactly two routes: `/` and the 404 page. No other pages.
- To build locally, `BASE_URL` must be set (e.g. `BASE_URL=https://hacktoberfest.com npm run build`) — the custom pre-build sitemap step throws on an empty hostname otherwise. This is pre-existing behavior, unrelated to any task below; always pass it when running `npm run build`.
- After every task's commit, `npm run build` must succeed.
